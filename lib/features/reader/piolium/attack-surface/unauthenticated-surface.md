# Unauthenticated Attack Surface

> Generated by piolium Q2 lite mode

## Target

`F:\App\zephyr_reader\lib\features\reader` (Flutter/Dart e-reader app)

## Summary

**This application has no active network-facing surface in its current state.** It is a local Flutter mobile e-reader that stores and reads content from the local filesystem via Dart/Rust FFI. However, the codebase contains one fully-implemented HTTP server that is **disabled by a comment guard**, and several local file-access entry points that could be reached by an attacker with device access.

### 2. Dictionary MDX file loading (`lib/features/reader/page/reader_dictionary_panel.dart`)

| Field | Value |
|-------|-------|
| Entry | `_ensureMdictConfigured` (called on `showDictionaryPanel`) |
| Trigger | User opens dictionary panel **and** no dictionary is configured, or saved path is missing |
| Why pre-auth | **missing-guard** — the dictionary file path stored in SharedPreferences is loaded with only an `existsSync()` check. If an attacker can modify app preferences (via backup attack, root, or ADB), they can point the app to read arbitrary `.mdx` files. |
| Attack class | Path traversal / insecure deserialization |

**Pre-auth reachability**: Requires device-level access (root, backup restore, ADB). Not network-pre-auth, but pre-auth in the sense that the dictionary loading path has no integrity verification.

### 4. HTML rendering of dictionary definitions
