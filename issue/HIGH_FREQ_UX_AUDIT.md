## 🟡 仍需改进

### P1 — 入口过深

| 操作 | 当前路径 | 问题 |
|------|----------|------|
| **跨书全局搜索** | 书架页 → 三点菜单 → 全球搜索 | 阅读中想跨书搜索需回书架再打开菜单。阅读器顶栏搜索是当前书内搜索，非全局 |
| **阅读记录** | 我的 → 学习管理 → 阅读记录 | Statistics tab 无入口，却放在个人中心下 |
| **分类管理** | 书架页 → 三点菜单 → 分类管理 | 书架核心功能，不应在 PopupMenu 里 |

### P2 — 入口不直观

| 操作 | 当前路径 | 问题 |
|------|----------|------|
| **书签管理** | 阅读器底栏「目录」→ 左抽屉 →「书签」tab →「书签管理」 | 路径 4 步。按钮写"目录"而非"书签"，用户不会想到从目录进书签管理 |
| **书本详情无搜索** | 无 | 进详情页后想搜索书中内容需到底部点「阅读」进入阅读器才能搜索 |

### 评为合理（不列入改进）

- **词典/翻译 API 设置**：个人中心下 3 层，属于一次性低频配置
- **学习笔记**：个人中心下 2 层，阅读中也可通过右侧笔记抽屉访问
