# 阅读核心功能 — 差距分析报告

> 对比主流阅读器（Kindle / Apple Books / ReadEra / Moon+ Reader / KOReader）

---

## 一、文件格式支持

| 格式 | Zephyr | 主流标准 | 差距 |
|------|--------|---------|------|
| EPUB 2/3 | ✅ 完整解析、富文本、CSS、多级目录 | ✅ 必备 | 无差距 |
| TXT | ✅ 多编码检测、自动章节分割 | ✅ 必备 | 无差距 |
| Markdown | ✅ 完整解析、富文本 | ✅ 常见 | 无差距 |
| PDF | ⚠️ Rust 侧文本提取完成，Dart 侧**未接入** | ✅ 必备 | **中等** — PDF 阅读器未接入 |
| MOBI / AZW3 | ❌ | ✅ 常见（Kindle 原生） | **大** — 缺 Kindle 格式 |
| FB2 | ❌ | ✅ 常见（FBReader 生态） | **小** — 小众格式 |
| CBZ / CBR | ❌ | ✅ 常见（漫画阅读） | **中** — 缺漫画格式 |
| DOCX | ❌ | ⚠️ 部分支持 | **小** — 非核心 |
| RTF | ❌ | ⚠️ 部分支持 | **小** — 非核心 |
| HTML | ❌ 无直接导入 | ✅ 常见 | **小** — 间接支持 |

**差距评估**: 整体主流格式覆盖约 60%。PDF 和 MOBI 是最大的缺口。

## 十四、结论

**核心阅读功能覆盖率约 85%**（修正后），基础阅读体验已经完整。

**P1/P2 列表中原 12 项，7 项已实现**：
- ✅ 进度条拖拽、无线传书、两端对齐、笔记导出、TTS 跟随、书架排序、批量管理

**仍缺失（10 项）**：
1. **PDF 阅读 UI**（Rust 已完成，只差接线）
2. **云盘直接同步**（Dropbox/GDrive — WebDAV 已覆盖基础）
3. 剩余时间估算（进度条只显示页码）
4. EPUB 图片渲染（分页模式）
5. 多色高亮选择器
6. 分享选中文本
7. 翻页速度调节
8. 屏幕常亮
9. 单本书阅读统计
10. 音量键翻页
