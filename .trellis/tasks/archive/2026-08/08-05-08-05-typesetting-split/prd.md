# 排版设置分工：阅读页精简常用项，设置页补齐完整排版

## Goal

调整排版/显示设置的展示分工：**阅读页设置面板只保留常用项，设置页（排版与字体）成为完整排版入口**。两侧共享同一份 `ReaderConfig` 持久化信号，改动只需调整各自面板的 UI 展示项。

## 背景（现状 2026-08-05）

阅读页有两个设置面板，设置页一个，两边覆盖项不一致：

| 设置项 | 阅读页·排版面板 | 阅读页·显示面板 | 设置页·排版与字体 |
| -------- | :---: | :---: | :---: |
| 字体族 | ❌ | ✅ | ✅ |
| 字号 | ✅ | ❌ | ✅ |
| 字重 | ❌ | ❌ | ✅（唯一入口） |
| 页边距 | ✅ | ❌ | ✅ |
| 行高 | ✅ | ❌ | ❌ |
| 字间距 | ✅ | ❌ | ❌ |
| 段间距 | ✅ | ❌ | ❌ |
| 首行缩进 | ✅ | ❌ | ❌ |
| 文本对齐 | ✅（平铺） | ❌ | ❌ |
| 阅读模式 | ✅ | ❌ | ✅ |
| 主题 | ❌ | ✅ | ❌ |
| 背景色 | ❌ | ✅ | ❌ |

全部映射到 `ReaderConfig` 持久化信号（`textAlign` 等），修改后下一次打开阅读器生效。

## Requirements（用户已确认）

1. **阅读页「排版」面板精简**，只保留常用项：
   - 字号、行高、页边距、文本对齐（平铺样式保留）、阅读模式
   - 移除：字间距、段间距、首行缩进（低频项）
2. **设置页「排版与字体」补齐完整排版项**：
   - 现有：字体族、字号、字重、页边距、阅读模式
   - 新增：行高、字间距、段间距、首行缩进、文本对齐（对齐方式用与阅读页一致的平铺样式）
3. **阅读页「显示」面板不动**（主题/字体族/背景色保持不变）。
4. 两侧共享 `ReaderConfig` 信号，行为一致：设置页改完，阅读页立即生效（反之亦然）。

## 非目标

- 不删除 `ReaderTextAlign.center/right` 枚举与 l10n key（避免存量设置读取出错）。
- 不改 `ReaderConfig` / `reader_config.dart` 信号结构。
- 不调整阅读页显示面板。

## Acceptance Criteria

- [ ] 阅读页排版面板不再显示 字间距/段间距/首行缩进。
- [ ] 设置页排版与字体页面包含：字体族、字号、字重、页边距、行高、字间距、段间距、首行缩进、文本对齐、阅读模式。
- [ ] 设置页文本对齐为平铺样式，选项与阅读页一致（跟随原书/左对齐/两端对齐），不含居中/右对齐。
- [ ] 阅读页显示面板无变化。
- [ ] `dart analyze --fatal-infos` 0 issue。
- [ ] `flutter test` 全绿（含 typesetting_panel_test 与 typography_settings_page 相关用例，按需新增/更新）。

## Notes

- 测试纪律：发现生产代码 bug 只记录，不临时改生产逻辑凑测试。
- l10n key：textAlignCenter/textAlignRight 等保留；textAlignment/行高/字间距/段间距/首行缩进等 key 设置页需要复用，若缺需补。
