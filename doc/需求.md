# Zephyr Reader 需求文档

## 项目概述
跨平台电子书阅读器 Flutter 应用，支持 TXT/EPUB/PDF 格式，提供滚动/翻页/双语三种阅读模式。

## 技术栈
- Flutter 3.41.2 + Dart 3.11.0, flutter_rust_bridge 2.12.0
- 状态管理: signals + setState
- DI: injectable + getIt; 路由: go_router 17.x; 数据类: freezed
- 数据库: SQLite (通过 Rust 层操作)
