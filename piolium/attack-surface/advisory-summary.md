| SQLite / redb KV | LOW | Local storage only |

### Trust Boundaries

1. External-to-App: WiFi transfer HTTP (when enabled) - no auth
2. Dart-to-Rust FFI: internal boundary - file validation without containment
3. App-to-Filesystem: local read/write to app data + user-selected directories
4. App-to-WebDAV: outbound HTTPS with credentials

### Highest-Risk Flows (for Phase 3 DFD)

1. WiFi Transfer to Book Import (disabled): HTTP upload to Rust parser to SQLite
2. WebDAV Sync: external data ingestion into book/progress storage
3. File Import to EPUB/TXT Parser: user-supplied files, format parser bugs
4. Dart-to-Rust FFI (getChapterContentIr): file path across FFI with partial validation
