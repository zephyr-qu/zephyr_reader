## 4. 体验承诺（能接受什么差距）

### 4.1 分页 vs 滚动（单选总体态度）

- [x] 接受：分页和滚动断页位置不必一致
- [ ] 希望：尽量接近，但不必像素级
- [ ] 要求：尽量一致（愿意为此多投入）

### 4.2 换章 / 加载（可多选「能接受」）

- [ ] 换章时有短暂 loading（<500ms 级）
- [ ] 换章时有明显 loading（<2s 可接受）
- [ ] 首屏可先空白/转圈，再出内容
- [x] 不接受任何 loading，宁可架构复杂（staging 等）

### 4.3 大书 / 大章（单选）

- [ ] 宁可慢一点，也要尽量完整 rich
- [x] 超过阈值就降级纯文本 + 明确提示（现状类似）
- [ ] 直接拒绝打开超大章
